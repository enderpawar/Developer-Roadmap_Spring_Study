## 2. 세션 예측과 교정 — Docker

| # | 질문 | 학습자 답 | 판정 | 교정 |
|---|---|---|---|---|
| P1 | 멀티스테이지 빌드에서 1단계 이미지의 JDK·Gradle 캐시가 최종 이미지에 남는가 | "안 남을 것 같다. 2단계에서 필요한 것만 복사하니까" | ✅ | 정확 — `COPY --from=build`로 jar만 넘어오고 1단계 이미지 자체는 최종 이미지에 포함되지 않음 |
| P2 | `runtimeOnly`로 MySQL 드라이버를 추가하면 기존 H2 기반 테스트에 영향이 있는가 | "영향 없을 것 같다. 테스트는 여전히 H2 URL을 쓰니까" | ✅ | 정확(61개 전부 그대로 통과로 확인) — Spring Boot가 JDBC URL 스킴으로 드라이버를 고름 |
| P3 | `depends_on`만 쓰고 `condition: service_healthy`를 안 주면 어떤 문제가 생기는가 | "mysql 컨테이너가 아직 완전히 안 떴는데 app이 먼저 붙어서 접속 실패할 수 있다" | ✅ | 정확 — 컨테이너가 뜬 것과 mysqld가 연결을 받을 준비가 된 것은 다른 시점 |
| P4 | Docker가 없는 이 머신에서 `compose.yaml`을 어디까지 검증할 수 있는가 | "문법은 확인할 수 있어도 실제로 뜨는지는 여기서 알 수 없다" | ✅ | 정확 — YAML 파싱과 의존성 해석까지가 이 머신의 한계, 실제 기동은 CI가 처음 검증 |
